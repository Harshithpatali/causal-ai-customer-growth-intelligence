# Research dataset

**Dataset:** Kevin Hillstrom / MineThatData Email Analytics Challenge (2008).

The experiment contains 64,000 observations assigned to Mens E-Mail, Womens E-Mail, and No E-Mail groups. The raw CSV is downloaded on first run to `data/raw/hillstrom.csv` by `src/causal_ai/data.py`.

The raw data is intentionally not committed. Review the original provider's terms before redistributing or mirroring it.

The source does not contain a unique customer identifier. Exact duplicate rows are retained; identical feature/outcome rows do not prove that two observations represent the same customer.

Source description: https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html
