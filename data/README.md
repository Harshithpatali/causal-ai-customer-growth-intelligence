# Dataset

Hillstrom / MineThatData Email Analytics Challenge, 2008.

The CSV is downloaded on first run to `data/raw/hillstrom.csv`. Do not commit the raw dataset unless you have confirmed redistribution rights. The dataset has 64,000 randomized customers in Mens E-Mail, Womens E-Mail and No E-Mail groups. Pre-treatment covariates include recency, history, prior category purchases, ZIP category, new-customer flag and channel. Post-treatment outcomes include visit, conversion and spend.
